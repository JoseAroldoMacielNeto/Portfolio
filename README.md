# Portfólio Profissional

Projeto de portfólio pessoal em HTML, CSS e JavaScript puros.

## Como executar localmente
1. Baixe/extraia a pasta "portfolio" inteira (mantendo a estrutura de subpastas).
2. Dê duplo clique no arquivo `index.html` para abrir no navegador.
   (Ou, no VS Code, clique com o botão direito em `index.html` e use a extensão "Live Server".)

## Personalização
- Troque `assets/img/foto-perfil.jpg` pela sua foto real.
- Troque `assets/img/projeto-placeholder.jpg` por capturas de tela dos seus projetos.
- Adicione seu currículo em `assets/docs/curriculo.pdf`.
- Edite os textos, links de redes sociais e e-mail diretamente no `index.html`.
